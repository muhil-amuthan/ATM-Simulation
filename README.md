# ATM-Simulation
The ATM Simulation System is a console-based Java application that simulates the basic operations of an Automated Teller Machine (ATM).
This project is developed using Object-Oriented Programming (OOP) concepts in Java and allows users to perform banking operations such as account creation, login authentication, cash withdrawal, deposit, balance inquiry, and PIN change.
The project is designed for engineering students and beginners to understand Java programming concepts and real-world banking system logic.
